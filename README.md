# Registers
This project run with Vue 2

# How to run

Download this repository 
===
    $ git clone <this_repo>
    $ cd <this_repo>
    $ git checkout feat/new_register
    $ npm install
    $ npm run serve

# Adds

This project runs with backend repo: backnode
